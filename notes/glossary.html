GLOSSARY

HyperText Markup Language HTML

HTML is the standard markup language for creating web pages. It describes the structure of a webpage and is used to
structure content.

+Element

A building block in an HTML document, defined by a start tag, content, and an end tag.

<p>This is a paragraph.</p>

+Tag

Tags are used to define the start and end of an element. Most tags come in pairs.

<p>This is a paragraph.</p>

+Attribute

Attributes provide additional information about an element, written inside the opening tag.

<img src="image.jpg" alt="Description">

+Doctype

Specifies the document type and version of HTML.

<!DOCTYPE html>

+Head Element

Contains metadata for the document, such as the title and link to external resources.

<head>
<title>Page Title</title>
</head>

+Body Element

Contains the content of the HTML document (text, images, links, etc.).

<body>
<h1>Main Heading</h1>
</body>

+Heading Tags (<h1> to <h6>)

Used to define headings, with <h1> being the highest level and <h6> the lowest.

<h1>Main Heading</h1>
<h2>Subheading</h2>

+Paragraph Tag (<p>)

Defines a paragraph of text.

<p>This is a paragraph.</p>

+Link Tag (<a>)

Creates hyperlinks. The href attribute specifies the URL.

<a href="https://example.com">Visit Example</a>

+Image Tag (<img>)

Inserts an image. The src attribute specifies the image URL, and alt provides a text alternative.

<img src="image.jpg" alt="An example image">

+List Tags (<ul>, <ol>, <li>)

Defines ordered or unordered lists, with list items defined by <li>.

<ul>
<li>Item 1</li>
<li>Item 2</li>
</ul>

+Table Tags (<table>, <tr>, <td>, <th>)

Used to create tables in HTML, with rows defined by <tr>, cells by <td>, and headers by <th>.

<table>
<tr>
<th>Header 1</th>
<th>Header 2</th>
</tr>
<tr>
<td>Row 1, Cell 1</td>
<td>Row 1, Cell 2</td>
</tr>
</table>

+Div Tag (<div>)

A block-level container used for grouping elements and applying CSS.

<div class="container">
<p>Content inside a div.</p>
</div>

+Span Tag (<span>)

An inline container used for styling part of the text or elements.

<p>This is <span class="highlight">highlighted</span> text.</p>

+Form Tag (<form>)

Defines a form for user input.

<form action="/submit" method="POST">
<input type="text" name="name">
<input type="submit" value="Submit">
</form>

+Input Tag (<input>)

Defines an input field for a form. Common types include text, password, submit, checkbox, and radio.

<input type="text" name="username">
<input type="checkbox" name="agree">

+Button Tag (<button>)

Creates a clickable button.

<button type="submit">Click Me</button>

+Label Tag (<label>)

Associates a label with a form control.

<label for="name">Name:</label>
<input type="text" id="name" name="name">

+TextArea Tag (<textarea>)

Defines a multi-line text input.

<textarea name="comments" rows="4" cols="50"></textarea>

+Select Tag (<select>)

Creates a dropdown list. Use <option> to define each option.

<select name="options">
<option value="1">Option 1</option>
<option value="2">Option 2</select>

+Meta Tag (<meta>)

Provides metadata about the HTML document, such as character set and page description.

<meta charset="UTF-8">
<meta name="description" content="Free Web tutorials">

+Script Tag (<script>)

Embeds JavaScript into an HTML document.

<script src="script.js"></script>

+Link Tag (<link>)

Links external resources such as stylesheets.

<link rel="stylesheet" href="styles.css">

Cascading Style Sheets (CSS)

CSS is a stylesheet language used for describing the presentation of a document written in HTML or XML. It defines how HTML elements are displayed on screen, paper, or in
other media.

+Selector

A CSS selector is the part of the CSS rule set that identifies the HTML element(s) you want to style.

h1 { color: red; }

+Property

A property in CSS refers to the type of style that you want to apply to an element.

p { color: blue; }

+Value

A value is assigned to a property to define its behavior.

p { color: blue; }

+Class Selector

A class selector allows you to apply styles to HTML elements that share the same class attribute.

.myClass { background-color: yellow; }

+ID Selector

An ID selector applies styles to an HTML element with a specific ID attribute.

#myId { font-size: 20px; }

+Box Model

The CSS box model describes the rectangular boxes generated for elements and consists of margins, borders, padding, and the content area.

+Padding

Padding creates space between the content of an element and its border.

div { padding: 20px; }

+Margin

The margin is the space around an element's border.

p { margin: 10px; }

+Float

The float property is used for positioning and formatting content.

img { float: right; }

+Display

The display property specifies how an element is displayed.

div { display: flex; }

+Flexbox

Flexbox is a CSS layout module designed for arranging elements in one-dimensional layouts (either rows or columns).

.container { display: flex; }

+Grid Layout

CSS Grid Layout is a two-dimensional layout system for web pages, controlling both rows and columns.

.grid-container { display: grid; grid-template-columns: 1fr 1fr 1fr; }

+Media Query

Media queries allow the content to adapt to different screen sizes and orientations (responsive design).

@media (max-width: 600px) { body { background-color: lightblue; } }

+Pseudo-Class

A pseudo-class is used to define the special state of an element, such as :hover when a user interacts with an element.

a:hover { color: red; }

+Z-Index

The z-index property specifies the stack order of elements, determining which elements appear in front or behind others.

div { z-index: 2; }

+Positioning

The position property specifies how an element is positioned in the document.

.box { position: absolute; top: 50px; left: 100px; }

+Opacity

The opacity property sets the transparency level of an element, where 0 is fully transparent, and 1 is fully opaque.

div { opacity: 0.5; }

+Background

The background property sets various background properties, such as the color, image, position, and repeat behavior of an element’s background.

body { background-color: #f3f3f3; }

+Important

The !important rule in CSS is used to apply a style with higher precedence, overriding any other style declarations, even inline styles.

p { color: blue !important; }

+Visibility

The visibility property specifies whether an element is visible or hidden, without affecting the layout.

div { visibility: hidden; }

+Text Alignment

The text-align property specifies the horizontal alignment of text within an element.

p { text-align: center; }

+Border

The border property is used to set the width, style, and color of an element’s border.

div { border: 1px solid black; }

+Overflow

The overflow property specifies what happens if content overflows an element's box.

div { overflow: auto; }

+Box Shadow

The box-shadow property adds shadow effects around an element's frame.

div { box-shadow: 2px 2px 5px grey; }

+Background Color

The background-color property defines the background color of an element.

body { background-color: lightblue; }

+Text Transform

The text-transform property controls the capitalization of text.

h1 { text-transform: uppercase; }

+Transition

The transition property allows property changes to occur smoothly over a given duration.

div { transition: all 0.3s ease-in-out; }

+Animation

The animation property allows for the creation of keyframe-based animations.

div { animation: slideIn 2s forwards; }

+Media Query

Media queries allow the content to adapt to different screen sizes and orientations (responsive design).

@media (max-width: 600px) { body { background-color: lightblue; } }

+Pseudo-Class

A pseudo-class is used to define the special state of an element, such as :hover when a user interacts with an element.

a:hover { color: red; }

+Z-Index

The z-index property specifies the stack order of elements, determining which elements appear in front or behind others.

div { z-index: 2; }

+Preload Function

The 'preload()' function is used to handle asynchronous loading of external files in p5.js. It runs before the 'setup()' function and is commonly used for loading assets like sounds, images, and fonts.

function preload() {
        ring = loadSound("data/ring.mp3");
      }

+Setup Function

The 'setup()' function is called once when the program starts. It initializes variables and sets up the environment, including the creation of the canvas and sound setup.

function setup() {
        createCanvas(windowWidth, windowHeight);
        ring.setVolume(0.007);
        text(txt, width / 2, height / 2);
      }

+CreateCanvas Function

The 'createCanvas()' function creates a canvas element in which all the p5.js drawing will take place. In this sketch, the canvas is dynamically set to fit the window size.

createCanvas(windowWidth, windowHeight);

+Draw Function

The 'draw()' function continuously executes the lines of code contained inside its block until the program is stopped. It is called automatically after 'setup()' and is used to render visuals on the canvas.

function draw() {
        background(220);
        ellipse(50, 50, 80, 80);
      }

+Background Function

The 'background()' function sets the color used for the background of the p5.js canvas. This function clears the canvas with a specific color in every frame.

background(220); // Light grey background

+LoadSound Function

The 'loadSound()' function loads a sound file for playback. In this sketch, the sound is played when interacting with particles.

ring = loadSound("data/ring.mp3");

+SetVolume Function

The 'setVolume()' function sets the volume level for the loaded sound. In this sketch, it is adjusted to a low level to match the user interaction volume.

ring.setVolume(0.007);

+Text Function

The 'text()' function displays text on the canvas at a specified location. In this sketch, it is used to show the 'txt' string at the center of the canvas.

text(txt, width / 2, height / 2);

+TextFont Function

The 'textFont()' function sets the font for the text displayed on the canvas.

textFont(fontFamily);

+TextAlign Function

The 'textAlign()' function sets the alignment for the text being drawn on the canvas. Here, it centers the text horizontally and vertically.

textAlign(CENTER, CENTER);

+Particles Class

The 'Particle' class defines the behavior of particles that move and interact with the mouse pointer. It contains methods for displaying and updating their position.

class Particle {
        constructor(x, y) { ... }
        display() { ... }
        update() { ... }
      }

+BlendMode Function

The 'blendMode()' function defines the blending mode for drawing operations. In this case, the 'ADD' mode is used to create an additive effect for the particles.

blendMode(ADD);

+MousePressed Function

The 'mousePressed()' function is called once every time the mouse button is pressed. It can be used to trigger an event or interaction based on mouse input.

function mousePressed() {
        fill(0); // Fill black on mouse click
      }

+MouseMoved Function

The 'mouseMoved()' function detects when the mouse is moved, resuming the audio context and playing the sound if particles are nearby.

function mouseMoved() {
        if (dist(p.x, p.y, mouseX, mouseY) < mouseRadius) {
          ring.play();
        }
      }

+GetAudioContext Function

The 'getAudioContext()' function accesses the Web Audio context and manages the audio state. In this sketch, it resumes the context when the mouse moves.

if (getAudioContext().state !== 'running') {
        getAudioContext().resume();
      }

+Dist Function

The 'dist()' function calculates the distance between two points in 2D or 3D space, used to detect mouse interaction with particles.

let dx = dist(this.x, this.y, mouseX, mouseY);

+LoadPixels Function

The 'loadPixels()' function loads the pixel data of the canvas into the 'pixels[]' array, which can be manipulated. It’s used in this sketch to generate particle data based on the text pixels.

loadPixels();
